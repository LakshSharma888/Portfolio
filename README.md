# My Portfolio

Welcome to my personal portfolio website. This project showcases my skills, qualifications, and projects. It is built using HTML, CSS, and JavaScript.

## Introduction

This is my personal portfolio website where I present my skills, qualifications, and projects. It is designed to give potential employers and collaborators an overview of my capabilities and experiences.

## Features

- Responsive design
- Interactive elements
- Smooth scrolling
- Dark/Light theme toggle
- Contact form

## Technologies Used

- HTML
- CSS
- JavaScript
- Swiper.js (for the project carousel)
- FontAwesome (for icons)
- Unicons (for additional icons)

## Sections

### Home

The home section includes a brief introduction about myself, links to my social media profiles, and a call-to-action button to contact me.

### About Me

This section provides a detailed introduction about my background, skills, and experiences. It also includes a link to download my resume.

### Skills

The skills section lists my technical skills, categorized into programming languages, IT constructs, and technologies.

### Qualifications

This section outlines my educational background, including details about my school and college education.

### Projects

The projects section showcases some of my recent work, with links to GitHub repositories and live demos.

### Contact

The contact section includes a form for visitors to send me a message, as well as my contact information.

## Usage

To view the portfolio, simply open the `index.html` file in a web browser. The website is fully responsive and can be viewed on any device.
